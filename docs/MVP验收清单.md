# MVP 验收清单

> 更新于 2026-11-02：30 项自动检查通过，补充人物审核发布、单客户包和停用恢复验证。现场打印、扫码或录屏保持未勾选；历史手机访问结果保留。

## 启动和入口

- [x] 新环境可以按 README 启动服务。
- [x] `/web/` 可以打开页面，根地址 `/` 会自动跳转到人物列表。
- [x] `?profile=<id>` 可以切换人物。
- [x] 非法或不存在的人物 ID 有明确回退或错误提示。

## 页面和交互

- [x] 页面在手机宽度下可操作。
- [x] 人物资料来自 `profiles/`，页面代码不写死客户资料。
- [x] 页面显示 AI 生成提示。
- [x] 页面说明形象不代表真人真实意识或意志。
- [x] 建议问题、手动输入和重置按钮均可用。
- [x] 重置同时清空模型历史与草稿，取消在途请求，忽略迟到回复。
- [x] 人物资料加载前禁止提问，加载失败时可重试。
- [x] 指定人物遇到服务故障时不会改用其他人物回答。

## 问答和语音

- [x] 等待时有状态提示。
- [x] 等待期间不能重复提交。
- [x] 空问题不会发起请求。
- [x] 回答来自人物资料或服务端返回结果。
- [x] 人物审核有效而模型失败时，服务端回退到审核回答；真实人物断网或人物不可用时停止缓存代答。
- [x] 语音失败时文字回答仍可见，按钮状态恢复。
- [x] 健康检查、人物加载与对话均有超时，超时后结束等待。
- [x] 人物列表加载失败可在当前页面重试。

## 交付

- [x] 人物 JSON 已完成资料审核（当前为两位虚构演示人物）。
- [x] 专属链接已生成并验证。
- [ ] 二维码已打印并用另一台手机扫描。
- [ ] 已准备备用热点和录屏。
- [x] 已记录客户素材来源和处理状态（当前为虚构演示素材）。
- [x] ZIP 包含 `一键启动.cmd`，解压至独立目录后服务启动和问答检查通过。
- [x] ZIP 排除本地环境文件及 `.env.*` 配置，保留空白示例。
- [x] 新人物草稿不在列表中，逐条审核、授权引用和当前版本校验通过后才可发布。
- [x] 修改内容使旧审核失效，重新发布自动归档前一版；写入失败恢复旧审核记录。
- [x] 单客户包不包含其他客户、草稿或原始证据，独立解压启动通过。
- [x] 模型适配器本地模拟供应商的成功、重试、异常和错误配置降级检查通过；不等同真实供应商联通。

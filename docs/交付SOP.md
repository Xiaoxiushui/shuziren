# 单客户交付 SOP

## 1. 建档

为客户分配小写短横线 ID，建立对应目录，登记素材来源、负责人和交付状态。

## 2. 采集和整理

发出《素材采集清单》，收到资料后只把已确认内容写入人物 JSON。缺失资料记录为待补充，不用猜测填充。

## 3. 配置人物包

按《人物配置流程》执行 `init → review → check → publish`。素材先在 `drafts/<id>/profile.json` 整理，审核人逐条确认来源与真实人物授权记录；未通过校验不得发布到人物列表。

## 4. 生成页面链接

使用 `scripts/generate_links.py` 生成专属链接和二维码文件，先用另一台手机扫码确认人物名称和欢迎语。

## 5. 演示验收

按《MVP 验收清单》逐项检查，记录问题、处理人和复验结果。

## 6. 交付归档

使用 `package_demo.py --profile <id>` 生成单客户包，检查清单中的人物 ID，避免夹带其他客户。归档人物 JSON、素材清单、审核记录、验收记录、二维码文件和交付日期。更新需重新审核并用 `publish --replace` 发布，旧版本自动归档。

# 数字纪念形象 Demo 产品说明

## 产品一句话

用户扫描纪念照片上的二维码，进入一个手机网页，查看人物简介，并与基于已审核生平资料生成的 AI 纪念形象进行文字或语音互动。

## 第一版交付范围

- 手机 H5 页面；
- 人物简介、照片占位和 AI 生成提示；
- 预设问题和文字问答；
- 浏览器语音播放；
- 真实服务失败时回退到审核过的演示回答；
- 每个人物使用独立 JSON 素材包和专属链接。

## 用户体验路径

1. 扫描二维码；
2. 看到人物简介和免责声明；
3. 点击建议问题或输入问题；
4. 获得文字回答并可播放语音；
5. 继续提问或重新开始。

## 当前版本边界

第一版不依赖实时数字人脸部驱动。人物回答以审核资料为依据，不对未知生平进行补写，并在页面持续显示 AI 生成提示。

# 数字纪念形象实施计划

## 总目标

在不依赖复杂自研的前提下，做出一个手机扫码即可体验的数字纪念形象 Demo，并沉淀为可以替换人物素材后重复交付的模板。

## 阶段一：产品边界和验收标准

输出：

- 一页产品说明
- 5 分钟现场演示脚本
- 第 3 档 MVP 验收清单
- 一个虚构人物素材包

验收标准：

- 手机打开页面后能看到人物介绍和明确的 AI 生成提示
- 用户可以输入问题并获得符合人物设定的回答
- 回答可以播放预置语音或合成语音
- 网络/API 失败时有可用的演示兜底

## 阶段二：H5 垂直切片

输出：

- 手机优先的互动页面
- 人物配置文件
- 对话状态和错误提示
- 本地演示模式

实现顺序：

1. 欢迎页和人物卡片
2. 对话输入与消息列表
3. 演示回答和语音播放
4. 人物资料替换机制
5. 二维码对应的专属页面参数

## 阶段三：真实服务适配

输出：

- 后端 API 适配层
- 大模型回答接口
- 语音合成接口
- 可选的语音识别接口
- 环境变量和错误重试策略

原则：页面不直接暴露服务商密钥；服务商可替换；真实服务不可用时自动回到演示模式。

## 阶段四：演示和交付能力

输出：

- 一键启动说明
- 一键生成人物页面和二维码的流程
- 演示视频和现场备份方案
- 素材采集清单
- 单客户交付 SOP

## 阶段五：小范围试点

先用 1 个虚构人物做内部测试，记录：

- 首次进入成功率
- 回答延迟和失败率
- 单份素材处理时间
- 用户是否理解这是 AI 生成形象
- 哪些问题最容易导致回答失真

完成虚构人物试点并取得已授权真实人物素材后，再执行真实人物内部试点。试点通过后，再增加动态形象和机构批量管理能力。

## 暂不做的事情

- 第一版不做实时直播级数字人
- 第一版不做复杂后台和多租户权限
- 第一版不做模型训练
- 第一版不追求一次接入多个服务商

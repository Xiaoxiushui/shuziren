# 手机访问与正式交付

## 两种地址必须区分

### 本机测试地址

只在运行服务的电脑上使用：

```text
http://localhost:4174/web/?profile=another-demo
```

这个地址不能直接给另一台手机使用。

### 局域网验收地址

让电脑和手机连接同一个 Wi-Fi，在电脑上执行：

```powershell
Set-Location "C:\Users\27106\Documents\ChatGPT\虚拟数字人"
.\scripts\serve.ps1 -Port 4174 -BindAddress 0.0.0.0
```

在电脑执行 `ipconfig`，找到当前 Wi-Fi 网卡的 IPv4 地址，例如 `192.168.1.23`，然后把链接中的 `localhost` 换成这个地址：

```text
http://192.168.1.23:4174/web/?profile=another-demo
```

先在电脑浏览器打开这个局域网地址，再用手机打开同一个地址。若 Windows 防火墙弹出 Python 网络访问提示，需要允许当前专用网络访问；不要把服务暴露到公共网络。

## 手机验收步骤

1. 电脑和手机连接同一个 Wi-Fi。
2. 用 `-BindAddress 0.0.0.0` 启动服务。
3. 用电脑 `ipconfig` 查出局域网 IPv4 地址。
4. 用电脑和手机分别打开相同的局域网链接。
5. 确认两台设备都显示正确人物名称和欢迎语。
6. 在手机点击建议问题，确认回答出现。
7. 将局域网链接交给 `generate_links.py` 生成二维码清单。
8. 用手机相机扫描二维码，确认进入的是对应人物页面。

## 正式交付地址

正式交付时，二维码内容应使用已部署的 HTTPS 域名，例如：

```text
https://memorial.example.com/web/?profile=another-demo
```

二维码只保存这个正式地址，不使用 `localhost`、局域网 IP 或临时端口。

## 为什么手机录音必须用 https

浏览器的麦克风只在**安全上下文**里可用：https 或本机 `localhost`。用 `http://局域网IP:端口` 打开时，浏览器会直接禁用麦克风，页面连权限弹窗都不会出现——这不是程序缺陷，改代码也绕不过去。

局域网内临时验证录音，可以给服务加自签名证书：

```powershell
# 一次性生成证书（需要 Git 自带的 openssl；证书含私钥，已在 .gitignore 里排除）
& 'C:\Program Files\Git\usr\bin\openssl.exe' req -x509 -newkey rsa:2048 -nodes `
  -keyout server\certs\key.pem -out server\certs\cert.pem -days 3650 `
  -subj "/CN=digital-memorial-local" `
  -addext "subjectAltName=IP:电脑局域网IP,IP:127.0.0.1,DNS:localhost"

# 以 https 启动（可与 http 端口并存）
py -3 server\server.py --host 0.0.0.0 --port 4443 --cert server\certs\cert.pem --key server\certs\key.pem
```

手机首次打开会提示"此连接非私密"或"证书无效"，点"继续访问"即可；证书里的 IP 必须与当前局域网 IP 一致，换网络后要重新生成。

**注意**：自签名证书只适合内部验证。正式交付必须用受信任的 https 域名，否则家属看到警告页会直接影响信任感。

## 一条命令起服务（默认带二维码）

`scripts/serve.ps1` 每次启动都会自动：算出当前局域网地址 → 把该地址的二维码刷到 `out\onsite\` → 打印电脑地址、手机地址和两张二维码路径。

```powershell
# http（能打字，手机上不能录音）
.\scripts\serve.ps1

# https（手机可录音；首次访问需在手机上信任自签名证书）
.\scripts\serve.ps1 -Port 4443 -Cert server\certs\cert.pem -Key server\certs\key.pem
```

二维码文件名固定为 `lin-shu-demo.png` 与 `another-demo.png`，换地址后重新启动即自动更新。

## 任意网络访问：临时公网隧道（演示用）

同一个 Wi-Fi 之外，还想用手机随时打开，可以起一条临时隧道：

```powershell
# 窗口 1：本机服务
.\scripts\serve.ps1

# 窗口 2：公网隧道（自动刷新二维码，并读出访问口令）
.\scripts\share.ps1
```

前提：`cloudflared.exe` 已放在 `%LOCALAPPDATA%\cloudflared\`（官方 Release 单文件，无需账号）。

要点：

- 隧道给的是 **https** 地址，因此手机录音可用，不需要再装证书；本机服务仍按 http 跑即可，TLS 在隧道侧终止。
- 地址形如 `https://随机名.trycloudflare.com`，**每次重启都会变**，所以二维码必须随之重新生成（`share.ps1` 已自动完成）。
- 公网暴露必须配合访问口令：`server/.env` 设置 `ACCESS_CODE` 后，`/api/*` 需要 `X-Access-Code` 头或网址参数 `k`；二维码会自动带上。
- 本机关机、断网或睡眠，公网地址立即失效。只适合演示，不适合对外交付。
- 对话内容会经隧道中转，不对第三方保密；真实逝者素材请勿走公开隧道。

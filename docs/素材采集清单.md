# 人物素材采集清单

## 必填资料

- 人物显示名称；
- 一句话简介；
- 照片可选（当前 MVP 使用照片占位，暂不处理真实照片）；
- 生平时间线和重要经历；
- 常用称呼、口头禅和语言习惯；
- 喜欢的事物、生活习惯和家庭称呼；
- 1 至 6 条首页建议问题，以及对应已确认回答；
- 不希望形象讨论的主题；
- 语音资源或浏览器演示语音选择。

## 资料处理规则

1. 每条事实标记为“已确认”“待确认”或“不得使用”。
2. 待确认内容不得进入人物回答资料。
3. 不把家属的推测写成逝者本人的观点。
4. 语气描述只写可观察的表达习惯，不写未经确认的心理判断。
5. 文件名使用人物 ID，不使用身份证号、手机号等敏感标识。
6. 人物资料只写可公开内容；每条审核项在私有 `review.json` 中记录 `sourceRef`，真实人物另外记录授权引用编号。原件另存，不进入人物 API 或模型上下文。
7. 资料内容修改后旧审核摘要失效，必须重新审核。详细命令见《人物配置流程》。

## 交付前检查

- [ ] JSON 可以被服务读取；
- [ ] 欢迎语经过家属或项目负责人确认；
- [ ] 示例问题的回答逐条审核；
- [ ] 边界问题有稳定的回退回答；
- [ ] 页面显示 AI 生成提示；
- [ ] 素材来源和处理记录已归档。

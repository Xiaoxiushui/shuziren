## MVP 范围

依据《产品说明》《实施计划》和《执行手册》，MVP 是可在局域网手机打开、可替换人物资料并重复交付的纪念 H5。包含人物列表、专属链接与二维码、简介与 AI 提示、建议问题和自由提问、最近四轮上下文、浏览器语音、重置、失败恢复、一键启动和 ZIP 交付。当前使用林叔、周姨两位虚构人物，不依赖外部供应商账号。

真实模型可通过现有 OpenAI 兼容适配器选配；真实供应商调用、服务端 TTS、真实人物试点和动态形象仍是 P3 后续工作。不能把配置齐全、本地模拟供应商测试或虚构审核夹具当作这些外部工作已完成。

## 已完成

- 重置同时清空草稿、消息和模型历史，取消请求并忽略迟到回复；请求都有超时和恢复状态。
- 人物资料加载前禁止发问；加载失败可重试，指定人物服务故障不会改用其他人物。
- 新人物完整流程：私有草稿 → 逐条来源审核 → 版本摘要校验 → 发布归档 → 专属链接 → 单客户 ZIP。真实人物需登记授权引用，内容更改必须重审。
- 服务每次请求验证人物；资料或审核失效返回 503，列表不展示，页面停止缓存代答。真实人物在网络失败时同样停止缓存回答；模型故障但资料审核有效时，服务端仍可返回审核答案。
- 默认包只包含两位虚构演示人物，指定人物包不夹带其他客户。审核记录仅保存在私有服务器文件，不通过 HTTP 或模型上下文提供。
- ZIP 包含一键启动、空白环境示例、文档和检查脚本，排除本地密钥、草稿、版本历史和生成输出。
- 模型适配器已验证成功、失败重试、超时、异常响应和错误地址降级；修复错误配置导致请求中断及异常历史角色导致清洗失败的问题。
